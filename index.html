What this is

A bot reads my Fantasy Premier League team, projects expected points over the next five gameweeks, weighs it against availability flags, and recommends changes before each deadline. Everything it recommends is logged here, along with what actually happened.

The interesting page is Calibration: predictions are cheap, and a bot that never scores itself is just a bot with opinions. The Squad page shows the current team, availability flags and every change made this season.
